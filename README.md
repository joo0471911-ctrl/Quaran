# আহসানুল বায়ান — আল-কুরআন ওয়েব অ্যাপ (ভার্সন v13)

একই স্ক্রিনে কুরআন তিলাওয়াত, অডিওর সাথে সিঙ্ক করা আরবি শব্দ + বাংলা উচ্চারণ + বাংলা অনুবাদ, তাফসীর আহসানুল বায়ান, সহীহ হাদীস এবং ক্বারী মিশারি রশিদ আল-আফাসির অডিও তিলাওয়াতসহ সম্পূর্ণ অফলাইন ও অনলাইন ওয়েব অ্যাপ।

## আপডেটসমূহ (v13)
- **একই স্ক্রিনে সিঙ্কড ভিউ:** অডিও চলার সাথে সাথে আরবি শব্দ, প্রতিটি শব্দের নিচে উচ্চারণ, পুরো লাইনের বাংলা উচ্চারণ এবং বাংলা অনুবাদ একই বক্সে পাশাপাশি/পরপর সাজানো হয়েছে যাতে বারবার নিচে স্ক্রল করতে না হয়।
- **লাইভ শব্দ হাইলাইট ও অটো-স্ক্রল:** তিলাওয়াতের অগ্রগতির সাথে সাথে শব্দগুলো হাইলাইট হয় এবং উপরের দিকে স্বয়ংক্রিয়ভাবে স্ক্রল করে।
