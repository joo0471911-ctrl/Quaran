# আহসানুল বায়ান (Ahsanul Bayan) — আল-কুরআন ওয়েব অ্যাপ

বাংলা অনুবাদ, তাফসীর, সহীহ হাদীস এবং ক্বারী মিশারি রশিদ আল-আফাসির অডিও তিলাওয়াতসহ সম্পূর্ণ ১১৪ সূরার অফলাইন-সক্ষম কুরআন রিডার।

## বৈশিষ্ট্যসমূহ (Features)
- **এক স্ক্রিনে সম্পূর্ণ পাঠ:** আরবি আয়াত, বাংলা উচ্চারণ, বাংলা অনুবাদ, তাফসীর (আহসানুল বায়ান) ও সম্পর্কিত সহীহ হাদীস একসাথে।
- **পূর্ণ স্ক্রিন আরবি রিডিং মোড:** আরবি আয়াতে টাচ করলেই বড় ফন্টে পূর্ণ স্ক্রিন পপ-আপ মোডে পড়ার সুবিধা।
- **ক্বারী মিশারি রশিদ আল-আফাসির তিলাওয়াত:** প্রতিটি আয়াতের জন্য পরিষ্কার অডিও প্লেয়ার, অটো-নেক্সট, রিপিট ও স্পিড কন্ট্রোল।
- **অফলাইন সাপোর্ট:** IndexedDB এবং Cache Storage ব্যবহার করে যেকোনো সূরা বা সম্পূর্ণ ১১৪ সূরার টেক্সট ও অডিও অফলাইনে সংরক্ষণের সুবিধা।
- **স্লাইড / সোয়াইপ নেভিগেশন:** ডানে-বামে সোয়াইপ করে সহজেই পরবর্তী বা পূর্ববর্তী আয়াতে যাওয়া যায়।

## GitHub Pages / Vercel / Netlify-তে হোস্ট করার নিয়ম
1. আপনার GitHub রিপোজিটরিতে `index.html` এবং `README.md` ফাইল দুটি আপলোড করুন।
2. **GitHub Pages** চালু করতে: `Settings > Pages > Branch: main / root > Save` সিলেক্ট করুন।
