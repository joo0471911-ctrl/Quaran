# আহসানুল বায়ান — আল-কুরআন ওয়েব অ্যাপ (ভার্সন v16)

- উপরের কুইক নেভিগেশন বক্সের ভেতরে `আরবি FS`, `আড়াল` এবং বুকমার্ক (`★`/`☆`) বাটনগুলো বক্সের সীমানার ভেতরেই সুন্দরভাবে ফিট করা হয়েছে।
- মূল পেইজে উপরের আরবি আয়াত হাইড করা হয়েছে এবং নিচের লাইভ সিঙ্ক বক্স শুধু মূল পেইজে শো করে।
- ফুল স্ক্রিন রিডিং মোডে গেলে লাল বক্সের ভেতরে আরবি আয়াত ও বাংলা অনুবাদ প্রদর্শিত হয়।

## ফাইলসমূহ
- `index.html` — লেআউট ও স্টাইল
- `script.js` — অডিও প্লেয়ার, লাইভ সিঙ্ক, অটো-স্ক্রল ও অফলাইন লজিক
- `README.md` — নির্দেশিকা
