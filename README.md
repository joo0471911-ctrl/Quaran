# আহসানুল বায়ান — আল-কুরআন ওয়েব অ্যাপ (ভার্সন v18)

- লাইভ সিঙ্ক স্টেজে ডাবল ক্লিক/টাচ করলে শুধুমাত্র লাইভ সিঙ্ক স্টেজটি আলাদা ফুল স্ক্রিন মোডে দেখা যায়।
- লাল বক্সের ভেতরে টাচ করলে রিডিং মোডের এফএসআরবি (FS আরবি) ফুল স্ক্রিন মোডে চলে যায়।
- দুটি ফুল স্ক্রিন মোডই আলাদা রাখা হয়েছে এবং উভয় মোড থেকেই আয়াত পরিবর্তন ও অডিও নিয়ন্ত্রণ করা যায়।
