# আহসানুল বায়ান — আল-কুরআন ওয়েব অ্যাপ (ভার্সন v14)

আলাদা `script.js` ফাইলসহ সম্পূর্ণ অফলাইন ও অনলাইন কুরআন ওয়েব অ্যাপ—যেখানে অডিও চলার সাথে সাথে আরবি শব্দ, প্রতিটি শব্দের নিচে উচ্চারণ, পুরো উচ্চারণ লাইন এবং বাংলা অনুবাদ একসাথে সিঙ্ক ও স্ক্রল হয়।

## ফাইলের তালিকা
- `index.html` — মূল ইউজার ইন্টারফেস ও স্টাইল
- `script.js` — অডিও সিঙ্ক, শব্দ হাইলাইট, অটো-স্ক্রল, বাংলা উচ্চারণ জেনারেটর এবং অফলাইন স্টোরেজ লজিক
- `README.md` — ব্যবহার নির্দেশিকা
