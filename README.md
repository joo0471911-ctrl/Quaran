# আহসানুল বায়ান — আল-কুরআন ওয়েব অ্যাপ (ভার্সন v20)

- FS আরবি (এফএস আরবি) ফুল স্ক্রিন মোডের বর্ডার, গ্লো ও বাটন স্টাইল লাল থেকে গোল্ড (`var(--accent-gold)` / সোনালী) রঙে পরিবর্তন করা হয়েছে।
- লাইভ সিঙ্ক স্টেজে ডাবল ক্লিক/টাচ করলে আলাদা লাইভ সিঙ্ক ফুল স্ক্রিন মোড এবং বক্সে টাচ করলে আলাদা FS আরবি ফুল স্ক্রিন মোড কাজ করে।
